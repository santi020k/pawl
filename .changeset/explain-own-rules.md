`pawl explain` knows every name pawl gives a finding. `pawl explain pawl/ai-keys` shows what a guard refuses, the level it runs at and whether it is on in the project, and `pawl explain pawl/sort-package-json` says how to fix that one. These names used to get "not in the pawl catalog" and exit code 1, though pawl's own output had printed them.
