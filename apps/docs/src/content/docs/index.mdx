A pawl is the part of a ratchet that stops it slipping backward. This tool does the same for a codebase.

<CardGrid>
  <Card title="One command" icon="rocket">
    `pawl init` detects the stack and the tools already in use, then writes small config files that point at the standard.
  </Card>
  <Card title="A ratchet" icon="approve-check">
    Existing findings go into a baseline. New findings fail the check, and so do new comments that switch a check off.
  </Card>
  <Card title="Built for agents" icon="star">
    `pawl check --changed --format agent` prints one compact line per finding, with the fix.
  </Card>
  <Card title="A company standard" icon="setting">
    Publish one policy package. Repos extend it, and locked rules cannot be loosened.
  </Card>
</CardGrid>
